This agent uses a 3-layer architecture:

  • Layer 1 - Data Index: Loads all CSVs, builds identity graphs with historical identifier resolution
  • Layer 2 - Evidence Parser: Parses SQL, JSON, TXT/LOG, PDF, and image evidence files
  • Layer 3 - Audit Engine: Applies deletion rules, reconstructs state at audit_at, generates ordered steps
